# 数学实验站

动手拖一拖、翻一翻、称一称，把数学看明白。

在线访问：https://billwang2012.github.io/mathlab/

1. [将军饮马实验室](horse/) v1.5.0：反射、平移、架桥、垂线最短、三动点与胡不归。拖动滑点，看折线怎样被拉直。
2. [代数叠叠卡](algebra-cards/) v1.3.4：翻面、叠合、抵消。用红黑卡片理解合并同类项与整体代换。
3. [方程平衡实验室](equation/) v1.3.17：把等式放上天平：两边同加、同减、同乘、同除，一步步解一元一次方程。
